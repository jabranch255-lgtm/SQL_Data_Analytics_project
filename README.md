# 📊 SQL Analytics & Business Intelligence Repository

A comprehensive collection of production-ready SQL scripts optimized for data exploration, advanced analytics, and reporting. This repository serves as a plug-and-play toolkit for data analysts and BI professionals to quickly extract actionable insights from relational databases.

## 🚀 Key Features
* **Theme-Based Organization**: Queries grouped by analytical goals.
* **Production Ready**: Optimized scripts following SQL best practices.
* **Tool Agnostic**: Standard ANSI SQL adaptable to most modern data warehouses.
* **Rapid Deployment**: Designed to accelerate ad-hoc data exploration.

## 📂 Repository Structure & Analytical Themes

### 🔍 1. Database Exploration
* Schema inspection
* Table row counts
* Missing value (NULL) detection
* Data type verification

### 📈 2. Measures & Metrics
* Key Performance Indicators (KPIs)
* Aggregations (SUM, AVG, MIN, MAX)
* Ratio calculations
* Distinct entity counting

### ⏱️ 3. Time-Based Trends
* Year-over-Year (YoY) growth
* Month-over-Month (MoM) growth
* Rolling window averages
* Period-over-Period comparisons

### 🔄 4. Cumulative Analytics
* Running totals
* Cumulative sums
* Year-to-Date (YTD) tracking
* Historical data stacking

### 🎯 5. Segmentation & Cohorts
* RFM (Recency, Frequency, Monetary) analysis
* Customer behavior cohort grouping
* Percentile ranking
* Data binning and categorization

## 🛠️ Best Practices Demonstrated
* Clean Common Table Expressions (CTEs) for readability.
* Advanced Window Functions (`SUM() OVER`, `LAG`, `LEAD`, `NTILE`).
* Explicit, optimized table joins.
* Descriptive aliasing for business-user-facing reports.
